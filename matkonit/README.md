# מתכונית 🍳

גרסה עברית לישראל של [TapCook](https://apps.apple.com/us/app/tapcook-budget-meal-plans/id6769601354):
רואים מתכון בטיקטוק, שומרים אותו בלחיצה, מתכננים שבוע ארוחות ערב בתקציב,
ומקבלים רשימת קניות עם מחיר משוער לפי הרשת שאתם קונים בה — רמי לוי, שופרסל,
אושר עד, ויקטורי, יוחננוף ועוד.

האפליקציה מותקנת למסך הבית (PWA), עובדת גם בלי קליטה בסופר, ומופיעה ברשימת
השיתוף של טיקטוק ואינסטגרם באנדרואיד.

## מה יש בה

| ב-TapCook | במתכונית |
|---|---|
| שיתוף סרטון מ-TikTok / Instagram / YouTube ← מתכון מסודר | אותו דבר, וגם Facebook וכל אתר מתכונים. Web Share Target באנדרואיד; באייפון מדביקים קישור. המתכון מתורגם לעברית, ביחידות מטריות ובשמות מצרכים כמו בסופר בישראל (heavy cream ← שמנת מתוקה 38%) |
| מצרכים, שלבים, זמנים, מנות | ✓, ובנוסף כשרות (בשרי/חלבי/פרווה), רמת קושי, קלוריות וטיפים |
| כשבכיתוב כתוב רק "המתכון בביו" | Claude מחפש את המתכון המלא של אותו יוצר ברשת לפני הייבוא |
| ספר מתכונים עם חיפוש | חיפוש לפי שם, מצרך, תגית או יוצר; סינון (מועדפים, מהיר, כשרות, מהרשתות), אוספים, מיון לפי מחיר או זמן |
| מתכונים שנוצרים ב-AI | "מה בא לכם" + "מה יש במקרר" ← מתכון |
| — | ייבוא מצילום מסך או מצילום של מתכון בכתב יד |
| תכנון שבוע ארוחות ערב לפי תקציב, גודל משק בית וערבי בישול | ✓, וגם תזונה, כשרות, דברים שלא אוכלים וזמן הכנה מקסימלי. מעדיף מתכונים מהספר שלכם ומנצל מצרכים בין ימים |
| רשימת קניות אחת מתומחרת לפי הסופר שבחרתם | ✓ לפי 12 רשתות ישראליות, באריזות שלמות, מסודרת לפי מחלקות |
| מסמנים מה כבר יש בבית והוא יורד מהסכום | ✓; מלח, שמן ותבלינים נחשבים "יש בבית" כברירת מחדל |
| — | השוואת סל הקניות בין כל הרשתות, תיקון מחיר של מוצר לפי הסניף שלכם, שליחת הרשימה בוואטסאפ |
| — | החלפת מנה אחת בתפריט, נעילת ימים, שינוי מספר הסועדים ליום |
| — | מצב בישול: שלב אחרי שלב, טיימרים שמזוהים מהטקסט ("אופים 25 דקות"), המסך לא נכבה |
| — | שינוי מספר מנות, דירוג, הערות, "בישלתי היום", הדפסה, גיבוי ושחזור, מצב כהה |

## הרצה

```bash
npm install
cp .env.example .env      # לא חובה
npm run dev               # http://localhost:5173
```

לפרודקשן:

```bash
npm run build
npm start                 # מגיש את dist/ ואת /api/ai על http://localhost:4173
```

### הפעלת ה-AI

ייבוא מסרטונים ומצילומים, יצירת מתכונים ותפריט חכם עובדים עם Claude. מוסיפים ל-`.env`:

```
ANTHROPIC_API_KEY=sk-ant-...
```

המפתח נקרא רק בשרת (`server/aiHandler.mjs`) ולא מגיע לדפדפן. ברירת המחדל היא
`claude-opus-5-5` (אפשר לשנות עם `MATKONIT_MODEL`). כל בקשה כוללת
fallback בצד השרת (`fallbacks: "default"`), כך שגם אם הבקשה נדחית בטעות
עדיין מתקבל מתכון. הקטלוג נשמר ב-prompt cache, כך שהקריאות אחרי הראשונה זולות יותר.

**בלי מפתח** האפליקציה עדיין עובדת: ייבוא מאתרי מתכונים שיש להם סימון
schema.org (רוב האתרים הגדולים, בשפת המקור), הזנה ידנית או הדבקת שורות,
ספרייה מובנית של 21 מנות ישראליות, מתכנן תפריט מובנה שעומד בתקציב,
רשימת קניות מתומחרת ומצב בישול.

## על המחירים

`src/data/catalog.json` כולל כ-120 מוצרי סופר עם מחיר משוער לאריזה ברשת
ממוצעת, ו-`src/data/stores.json` כולל מדד מחיר לכל רשת (רמי לוי 0.90,
שופרסל דיל 1.00, AM:PM 1.22…). המחיר ברשימה = מחיר האריזה × מדד הרשת ×
מספר האריזות שצריך לקנות.

זו **הערכה**, לא מחירון. מחיר שגוי מתקנים בלחיצה עליו ברשימה, והתיקון נשמר
לכל הרשימות הבאות. בישראל רשתות השיווק מפרסמות מחירים מלאים לפי חוק שקיפות
המחירים, אז השלב הבא הטבעי הוא לייבא את הקבצים האלה במקום המדד. כל מה
שצריך להחליף זה `unitPrice` ב-`src/lib/pricing.ts`.

## התקנה בטלפון

- **אנדרואיד**: Chrome ← תפריט ← התקנת אפליקציה. מעכשיו "מתכונית" מופיעה ברשימת השיתוף של טיקטוק ואינסטגרם.
- **אייפון**: Safari ← שיתוף ← הוספה למסך הבית. iOS לא מאפשר לאפליקציות ווב להופיע ברשימת השיתוף, אז מעתיקים קישור ולוחצים "הדבקה".

## פריסה

**Vercel**: מגדירים Root Directory = `matkonit` ומוסיפים `ANTHROPIC_API_KEY`.
`vercel.json` ו-`api/ai.mjs` מטפלים בשאר. בניית תפריט שבועי יכולה לקחת יותר
מ-60 שניות, לכן `maxDuration` מוגדר ל-300 (דורש Pro). ב-Hobby, אם הזמן נגמר,
האפליקציה עוברת למתכנן המובנה.

**בכל מקום אחר**: `npm run build && npm start`.

## פרטיות ואבטחה

הכל נשמר במכשיר (localStorage). ל-Anthropic נשלחים רק תוכן המתכון שמייבאים,
העדפות משק הבית ושמות המתכונים בספר (לתכנון). השרת מוריד קישורים שמדביקים,
ולכן הוא חוסם כתובות פנימיות (localhost, רשתות פרטיות, metadata של ענן) ובודק
כל הפניה מחדש.

## מבנה

```
server/            ייבוא ו-AI: חילוץ מסרטונים ואתרים, פרומפטים, סכמות, ניקוי
  aiHandler.mjs    /api/ai — אותו handler ב-dev, ב-Vercel וב-npm start
  extract.mjs      oEmbed של TikTok/YouTube, תגיות og, JSON-LD, הגנת SSRF
src/data/          קטלוג מוצרים, רשתות, ספריית מתכונים מובנית
src/lib/           תמחור, מתכנן, ניתוח שורות מצרכים, התאמה לקטלוג, אחסון
src/screens/       ספר מתכונים, מתכון, מצב בישול, ייבוא, עורך, תפריט, קניות, הגדרות
```
